# Too Good Co Frontend Clone

A frontend clone of the Too Good Co website built using HTML, CSS, and JavaScript. This project focuses on recreating a modern, interactive UI with smooth animations, custom typography, responsive layouts, and engaging user experience elements.

## 🚀 Features

- Smooth hover animations
- Modern UI inspired by Too Good Co
- Responsive navigation bar
- Custom fonts integration (Futura)
- Custom cursor effect
- Video section with interactive play button
- Image sections with hover interactions
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Custom Fonts
- Flexbox

## 📂 Project Structure


## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Komala-L/Too-Good-Co-Frontend-Clone.git
```

2. Navigate into the project folder

```bash
cd Too-Good-Co-Frontend-Clone
```

3. Open `index.html` using Live Server or any browser.
